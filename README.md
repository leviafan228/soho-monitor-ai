# SOHO Monitor — система моніторингу SOHO-маршрутизаторів

Вебсистема для дистанційного моніторингу домашніх і малих офісних (SOHO) маршрутизаторів.
Система цілодобово перевіряє доступність роутера, збирає телеметрію, визначає причину втрати
зв'язку (відключення електроживлення чи аварія провайдера) і надсилає сповіщення в Telegram.

Статус: навчальний прототип.

## Можливості
- фонове опитування маршрутизаторів кожні 5 секунд;
- алгоритм непрямої діагностики збоїв живлення за лічильником uptime;
- двофазні сповіщення в Telegram (тривога та звіт після відновлення);
- веб-панель з графіками та журналом інцидентів.

## Технології
Node.js + Express, MongoDB (Mongoose), React, Chart.js, Telegram Bot API.

## Структура
```
backend/   — REST API, фонове опитування, аналіз інцидентів
frontend/  — веб-панель (React)
```

## Запуск
```bash
cd backend && npm install && cp .env.example .env && npm start
cd frontend && npm install && npm start
```
